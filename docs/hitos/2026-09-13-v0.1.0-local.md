# v0.1.0 local validation

Date: 2026-09-13. Status: implementation verified locally; public repository destination awaiting confirmation.

## Acceptance evidence

- `BTOFOLDERLOOP_NATIVE_TRASH_TEST=1 swift test`: **23 tests, zero failures, zero skips**. Includes native Trash and SQLite integration. The default CI invocation intentionally skips the one native Trash test.
- A three-level synthetic chain in single mode moved only the leaf. A subsequent cascade moved the remaining parents. The original control file kept its bytes and identity; all native Trash destinations were checked.
- Native UI flow: choose a generated fixture, preview, open/cancel confirmation, verify zero journal runs and unchanged directory; approve single mode (one move); select cascade (two parents shown and moved). UI reported zero errors. A separate Python/SQLite read verified all original file hashes/inodes, packages, symbolic link and its target, moved destinations, and database integrity.
- Quit and reopen the packaged application against the same local SQLite store: cascade preference persisted in the UI. The history displayed both completed operations. No cleanup starts on reopening.
- Packaged `.app` started successfully with the migration resource inside its own Resources directory. The storage module no longer relies on SwiftPM's absolute build-path resource fallback.
- A 10,000-directory in-memory planning fixture completed in approximately **0.20 seconds** on the validation machine. This measures planner performance, not disk or cloud-provider throughput.
- Source privacy check and binary scan exclude private home/build paths from the public artifacts. Code indexing completed locally; the index reports partial parsing for the native I/O declarations and SQL pragmas. It is not part of the repository.

## Reproduce

```sh
swift test
BTOFOLDERLOOP_NATIVE_TRASH_TEST=1 swift test --filter StorageAndNativeTests/testNativeSingleAndCascadeTrashWithOriginalFilePreserved
bash scripts/build-app.sh
python3 scripts/check-public.py
```

UI fixtures and raw evidence contain local paths and remain outside version control. Only this sanitized result is public. Drag-and-drop is implemented with SwiftUI URL transfer; the validated UI entry path was the folder chooser. Additional cross-application drag and macOS/provider compatibility cases remain in the next validation matrix.

## Limits

Initial binary: Apple Silicon, macOS 14+ target, tested on macOS 26. No Apple Developer notarization. No Windows/Linux build. Concurrent writers and references outside the selected tree cannot be fully controlled. The preview is the maximum authorized set; unknown or occupied entries are preserved. Protected empty packages and known link targets intentionally remain.

No user archive was cleaned as part of these tests. Only generated fixture directories were moved; Trash was never emptied.
