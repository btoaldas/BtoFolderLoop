## Limits and follow-up ideas

This preview is locally signed ad hoc and is not notarized by Apple. A successful CLI download/runtime test does not establish a Gatekeeper-approved browser first launch. No security settings were changed and the workflow did not overwrite an installed application. The SQLite schema is unchanged.

Cross-application drag-and-drop and a broader macOS/cloud-provider matrix remain explicit follow-up checks. Selection is never expanded implicitly; external writers and later Trash emptying affect recovery as described in SECURITY.md.

Suggested next features, not implemented in this release: hierarchical selection view, persistent explicit exclusions, and guided restoration only from destinations that still exist without overwriting any path. These require their own scope and acceptance criteria. This sanitized record is ready for a separately authorized knowledge-vault snapshot; raw data and live databases are not exported.
