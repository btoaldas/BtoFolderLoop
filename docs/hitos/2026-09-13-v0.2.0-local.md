# v0.2.0 local acceptance

Date: 2026-09-13. Initial implementation and local packaging verified; public release verification follows separately.

## Evidence

- `BTOFOLDERLOOP_NATIVE_TRASH_TEST=1 swift test`: **33 tests, zero failures and zero skips**. The default CI run intentionally skips the two opt-in native Trash cases.
- Nine core selection cases cover default-off, all/none, individual toggles, stale or unknown candidates, immutable approval, non-expansion, parent/child dependencies and post-approval filesystem changes. The native partial-selection case moves one selected leaf, preserves the unselected intermediate folder and sibling, and verifies the original file and Trash destination.
- Packaged native UI on a generated tree: zero of three candidates selected at first; all/none updates each checkbox; an individually selected row remains selected through filtering; the confirmation shows both selected rows even when one is hidden. Cancel produces zero journal runs and unchanged directories.
- Switching to cascade resets the selection to zero of five. Selecting only a leaf and its ancestor moves the leaf, skips the occupied ancestor and preserves the intermediate unselected folder. Switching back to single-pass starts unchecked and moves only one chosen candidate. Re-analysis clears a previously marked selection.
- Independent SQLite/filesystem inspection confirms the approved run counts (cascade: planned 2, moved 1; single-pass: planned 1, moved 1), zero errors, original file bytes/identities, protected package/link target and unselected directories. SQLite integrity is `ok`.
- Original OpenAI-generated raster icon is visible in the main window, complete-selection confirmation and native About panel. About shows version 0.2.0 (2). Icon packaging contains ten standard/Retina representations from 16 to 1024 pixels, with alpha. Source image remains unchanged and generation provenance is public.
- App compilation, native signature verification and packaged-resource privacy checks pass. Raw screenshots, database paths and fixtures remain outside Git.

## Limits

Only artificial directories were used in cleanup tests. The application never empties Trash; later recovery requires the recorded destinations still to exist. This preview has an ad-hoc local signature and no Apple notarization. Compatibility and cross-application drag-and-drop matrix expansion remain separate work.
