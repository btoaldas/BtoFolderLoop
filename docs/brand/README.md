# BtoFolderLoop application identity

Intent: a recognizable folder with a single circular return arrow communicates the folder loop. A broad cyan silhouette and mint arrow on a navy tile remain readable at small sizes. This is an application identity, not a claim of cloud synchronization or permanent file removal.

Source: `Sources/BtoFolderLoopApp/Resources/BrandIcon.png`, 1254 × 1254 pixels, PNG with alpha, created using OpenAI's built-in image-generation tool on 2026-09-13. This is an AI-generated raster original, not an editable vector. No external brand references or user files were supplied. The source is included with this GPL-3.0-or-later project.

The source file is retained unchanged. `scripts/build-icon.sh` performs only size exports with macOS `sips` and packages ten standard/Retina representations with `iconutil`. The same source is shown in the app and README. The `.icns` is embedded in each built `.app`; no private generation paths are required at runtime.

## Generation prompt

Use case: logo-brand. Create one original production-ready macOS application icon for BtoFolderLoop, a careful local utility that sends only user-selected empty folders to Trash. Asset: a single square 1024x1024 icon, no words or letters. Subject: a simple open folder outline integrated with one clear circular return arrow, conveying folders and a controlled loop. Thick clean geometric strokes, balanced negative space, instantly readable at 32 pixels. Fresh cyan-blue folder with a small mint circular arrow on a deep midnight-navy rounded-square tile; the tile fills about 88 percent of the canvas with softly rounded corners and true transparent area outside the tile. Flat polished minimal software identity, subtle depth only, no glossy plastic, no gradients unless very subtle, no photos, no mockup, no additional icons, no watermark, no trademarked or borrowed logos. The folder silhouette must remain dominant; the single arrow must clearly suggest one loop, not a cloud sync badge. Output only the finished icon centered, no presentation sheet.

## Review

The generated source was visually reviewed for a dominant folder silhouette, a clear circular arrow, no lettering, and transparent tile margins. Final small-size, Finder/Dock and in-app checks are recorded with the v0.2.0 milestone.
